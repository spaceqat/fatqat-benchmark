# Quantum Benchmark Repositories

This document collects open-source benchmark suites and tools for evaluating quantum circuits, compilers, simulators, software development kits, and quantum hardware.

## Benchmark Suites

| Project | Focus | Main formats or frameworks | GitHub |
| --- | --- | --- | --- |
| NWQBench | Configurable generators for near-term quantum benchmark circuits | OpenQASM, Qiskit, Cirq, PyQuil, and Q# | [pnnl/nwqbench](https://github.com/pnnl/nwqbench) |
| QASMBench | Low-level benchmark circuits for NISQ evaluation and simulation | OpenQASM 2 | [pnnl/QASMBench](https://github.com/pnnl/QASMBench) |
| MQT Bench | Cross-level benchmarks for quantum software tools, from algorithms to mapped circuits | OpenQASM 2, OpenQASM 3, QPY, and Python | [munich-quantum-toolkit/bench](https://github.com/munich-quantum-toolkit/bench) |
| SupermarQ | Scalable application benchmarks and circuit-feature metrics for quantum systems | Cirq and Qiskit | [Infleqtion/client-superstaq — supermarq-benchmarks](https://github.com/Infleqtion/client-superstaq/tree/main/supermarq-benchmarks) |
| QED-C Application-Oriented Benchmarks | Application-level benchmarks for comparing quantum platforms and backends | Qiskit and CUDA-Q | [SRI-International/QC-App-Oriented-Benchmarks](https://github.com/SRI-International/QC-App-Oriented-Benchmarks) |
